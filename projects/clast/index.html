CopyLast / clast

A PowerShell 7 utility built around one small but recurring annoyance: getting the previous command together with the output you actually saw, without replacing the native prompt.

PowerShell 7+WindowsCLIMITNo prompt replacement
View repository ↗Portfolio

Problem

Sharing terminal context is surprisingly awkward when the useful artifact is not just a command, but the exact visible output that followed it.

Approach

CopyLast reads the active PowerShell transcript and extracts the previous command plus the visible output, then provides a clean preview / copy / reset workflow.

Workflow

Run command
Transcript records
clast parses
Preview
Clipboard

Design priorities

  • Keep the native PowerShell prompt.
  • Make the behavior easy to inspect.
  • Stay dependency-light.
  • Optimize for repeated daily use.

Why it matters

It is a small tool, but it represents the kind of engineering I like: remove friction once, then stop paying the same manual cost every day.
